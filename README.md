# 隐私政策

## 智物 - 智能物品管理助手

### 生效日期：2026年3月5日

### 概述
智物重视您的隐私。本隐私政策说明我们如何收集、使用、存储和保护您的个人信息。

### 信息收集

**您主动提供的信息：**
- 物品信息：名称、分类、位置、描述、价格等
- 照片：您为物品拍摄的照片
- 借出记录：借用人信息、借出时间等

**自动收集的信息：**
- 设备信息：设备型号、操作系统版本
- 使用数据：功能使用情况、错误日志

### 信息使用
我们收集的信息仅用于：
- 提供和应用核心功能
- 改善用户体验
- 故障诊断和技术支持

### 数据存储
- 您的数据存储在本地设备
- 支持数据导出备份到本地文件
- 不自动上传到任何服务器

### 第三方服务
本应用不包含任何第三方分析或广告服务。

### 数据安全
我们采取合理的技术措施保护您的数据安全。

### 儿童隐私
本应用不面向13岁以下儿童。

### 政策更新
我们可能随时更新本政策，更新后将在应用内公告。
